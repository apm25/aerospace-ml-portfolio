# Aerospace & Machine Learning Portfolio

This repository tracks my progress in learning the foundations machine learning and data engineering, in preparation to apply them to aerospace concepts for future projects. My background is in aerospace engineering, and I am building a software foundation geared toward CFD optimisation, surrogate modeling, and F1 telemetry analysis.

## Repository Structure

* **01_OOP**: Core Python object-oriented programming labs, interfaces, and modular software design.
* **02_Data_Analysis**: NumPy vectorization and Pandas data manipulation. The focus here is on efficiently handling large arrays and time-series data, similar to aerodynamic mesh grids or vehicle sensor logs.
* **03_Machine_Learning**: Training predictive models using Scikit-Learn and PyTorch, eventually building up to reduced-order models for flow fields.

## Tech Stack
Python, NumPy, Pandas, Scikit-Learn, PyTorch, Jupyter, Git.
